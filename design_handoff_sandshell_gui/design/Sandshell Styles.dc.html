Sandshell · macOS · 3 styles
One workspace, Projects → Sessions, live agent terminals
Each window is one workspace folder backed by a single sbx container. The sidebar is the Projects → Sessions source list you liked — every project carries a “New Session” row and the footer adds a project. Selecting a session shows its Claude Code or Codex terminal, with a live “time spent working”. Three fixed looks: light, a dark sidebar with a light terminal, and full dark.
